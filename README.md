# 🎓 英语六级词汇刷题系统

一个**单文件、完全离线可用**的 CET-6 词汇刷题系统，词库严格来自两本纸质教辅书，支持 PWA 安装到手机/电脑，像原生 App 一样全屏使用。

> **在线体验**：https://adrian0314.github.io/cet6-cihui-shuati/%E5%85%AD%E7%BA%A7%E8%AF%8D%E6%B1%87%E5%88%B7%E9%A2%98%E7%BD%91%E7%AB%99/cet6_quiz.html

### 释义质量检查

仓库提供数据质量扫描脚本，用于检查词性/音标格式异常，并列出全库标准化中文释义重复组与高重叠释义对。重复组仅用于质量审查，不代表需要删除词条：

```text
node 六级词汇刷题网站/tools/scan_meaning_bugs.js
```

脚本不会修改词库。英文选中文模式会在生成选项时过滤碰撞释义；中文选英文模式保持原有取题行为。

## 📖 使用指南

### 开始做题

做题页从上到下依次设置：**词库 → 单元筛选 → 闯关模式 → 做题模式 → 题目类型 →（可选）记忆模式 → 每次学习量**，然后点「▶ 开始做题」。

- **做题模式**：看中文→选英文 / 看英文→选中文
- **题目类型**：选择题（四选一，遇到已知缺失释义的词条会自动修复显示，例如 `animal` 会显示“动物”）/ 默写题（键盘输入或手写板）
- **重点词**：做题时在单词标题与音标右侧点击「☆ 标记重点」或「★ 已标记」添加/取消当前单词；切换题目后按钮会跟随当前单词并保留状态，状态也会同步到重点词列表和智能练习
- **每次学习**：1 页≈20 词，可选 1/2/3 页
- **页导航**：单选某个 Unit 做题时，顶部显示「第 X/Y 页」与本页进度；自动从上次做到的位置续刷（学完整个 Unit 最后一页后自动回到第 1 页），也可用「上一页/下一页」跳转任意页
- **答题进度**：顶部进度条中绿色表示已完成，灰色表示未完成，青绿色高亮表示当前题；切换上一题、下一题或输入题号跳转时会自动滚动跟随当前题，尽量保持在进度条中间，首尾题则停留在对应边界
- **中途退出**：做题进行中会即时把当前题位、已答数量和已选答案写入本地存储；手机切到后台、刷新页面或关闭网页时，页面生命周期事件还会再次保存，重新打开后点击顶部「继续做题」即可接着完成同一队列。手机从其他应用返回后的短暂恢复保护会忽略浏览器补发的旧「不会，跳过」点击，确认新的触摸后仍可正常操作。4 周 25 天计划会同时保存当日进度，复习提醒也会显示实际的已完成题数和待完成题数；进入新的一天后，旧日未完成队列会按新的每日计划重置
- **朗读发音**：点击单词旁的喇叭按钮优先使用普通媒体音频，以便跟随视频/音乐的蓝牙输出；网络音频无法播放时自动回退到系统 TTS，离线时仍可使用系统 TTS
- **答题后信息顺序**：提交答案或跳过后，题目与正确答案下方紧接默认展开的“📖 单词详解”（巧记、例句、派生词）；随后显示“⚠️ 易混淆词”辨析和词群归属信息，最后显示“🗺️ 词群导图”。点击标题可收起或重新展开单词详解内容。

### 🏰 闯关模式

| 关卡 | 名称 | 用法 | 适用场景 |
|---|---|---|---|
| 闯关1 | 词群速记 | 认识/不认识二选一快刷：**认识**直接进入下一词，**不认识**先展示默认展开的单词详解，再显示词群导图。快捷键 `1`/`空格`=认识，`2`=不认识 | 首次接触新词群，快速过一遍混个脸熟 |
| 闯关2 | 选择检测 | 标准四选一 / 默写题，答完即显示详解 | 学完一个 Lesson 后的检测 |
| 闯关3 | Unit 综合测 | 一次覆盖整个选中 Unit 的全部词 | 学完一个 Unit 后的综合检测 |

**取题量**：闯关1/2 按「每次学习」页数取词；闯关3 一次性测完整个选中单元（忽略页数）。做题中切换闯关模式会先保存当前进度。

### 🗺️ 词群导图

答完题自动显示当前词的词群关系图（单词浏览器点「🗺️ 导图」按钮也可查看）——中心=词群主题或当前词，四周圆圈=关联词：

- **分支徽标**：圆圈外侧的绿色数字徽标表示该词下面还有几个分支；点击带徽标的圆圈逐层展开，没有徽标的圆圈=末端词（无分支），点击朗读发音
- **连线颜色**：绿=派生（扩/合成）、蓝=同根、橙=近义、红=反义、粉=形近、灰=相关，虚线=形近/反义
- **覆盖范围**：大纲词汇 Unit 1-10（书页真实导图）；导图未覆盖的词自动回退旧版导图

### 🧠 记忆模式

点「🧠 记忆模式」按钮开启，做题时**做完一题即从队列移除**，答错的词按当前词库的书中记忆规律自动排期回来复习：

- 每次进入记忆模式的队列 = **到期复习词** + 当前选中范围内的**未学新词**
- 做完一题即删，不回头重复；答错词进入记忆调度，到期自动回来

**记忆规律：**
- 大纲词汇 → 书末「4周25天打卡表」：按 **+1天/+3天/+6天/+12天** 间隔复习
- 核心词汇 → 书中每词 8 格周期：**5分/30分/12时/1天/2天/4天/7天**

**到期复习：**
- 打开网页时若有到期单词，做题页顶部显示绿色**复习横幅**，点「开始复习」四选一快刷一键清债，跳过视同答错
- 5分/30分 这类短周期在学习会话内实时提醒

注意：记忆模式是独立于闯关等级的学习方式开关，开启后按记忆调度自动排程（不按页取题）；复习只从首次作答开始计，历史数据不迁移。

### ⌨️ 快捷键

- 数字 `1-4`：选择题选答案
- `空格`：跳过（闯关1 中为「认识」）
- `回车`：下一题
- `2`：（闯关1 中为「不认识」）

## 🚀 快速开始

### 方式一：本地使用

进入 `六级词汇刷题网站/` 目录，直接双击 `六级词汇刷题网站/cet6_quiz.html` 用浏览器打开即可。

### 方式二：安装为 App

1. 部署到任意静态托管（GitHub Pages / Netlify / Vercel）
2. 用手机浏览器打开链接：
   - **安卓**：Chrome/Edge → 菜单 →「添加到主屏幕」
   - **iPhone**：Safari → 分享 →「添加到主屏幕」
3. 安装后全屏运行、可离线使用，数据存在本地

> 注意：PWA 安装需通过 https 地址访问，本地双击打开不支持安装。

### 方式三：词群编辑器（维护工具）

仓库附带词群导图编辑工具链，需本机安装 [Node.js](https://nodejs.org/)（建议 18+）：

1. 在 `六级词汇刷题网站/` 目录双击 **`打开词群编辑器.bat`**：自动检测词典服务端口（17989），未运行则拉起 `node dict-server.js`，随后在浏览器打开 `word-map-editor.html`
2. 编辑器支持：从有道词典抓取单词讲解（本地服务离线时尝试直连）、可视化编辑词群导图节点、保存回 `六级词汇刷题网站/data/unit-maps.js`
3. 也可单独双击 `六级词汇刷题网站/启动词典服务.bat` 只启动服务；改完导图重新发布即可更新网站的词群导图

> 说明：`dict-server.js` 仅用 Node 内置模块（http/https/fs），无 npm 依赖；词典数据来自有道公开接口。

### 方式四：手机快速使用

手机上点击这个链接 **https://adrian0314.github.io/cet6-cihui-shuati/%E5%85%AD%E7%BA%A7%E8%AF%8D%E6%B1%87%E5%88%B7%E9%A2%98%E7%BD%91%E7%AB%99/cet6_quiz.html**，用浏览器打开，点击右上角三个点，点击 **「添加到主屏幕」** 即可在桌面快速点击使用（全屏运行、可离线）。

### 方式五：词群导图查看器（只看导图）

不想做题、只想浏览词群导图时使用——Unit 1-10 全部词群整树展示，不用一个一个点节点：

- **在线版**：https://adrian0314.github.io/cet6-cihui-shuati/%E5%85%AD%E7%BA%A7%E8%AF%8D%E6%B1%87%E5%88%B7%E9%A2%98%E7%BD%91%E7%AB%99/word-maps-viewer.html
- **离线单文件版**：双击 `六级词汇刷题网站/word-maps-viewer-offline.html`（数据已内联，单文件可拷到 U 盘/手机/别的电脑，无需网络、无需 data 目录）
- **离线外置版**：双击 `六级词汇刷题网站/word-maps-viewer.html`（需与 `六级词汇刷题网站/data/` 目录同放）
- 功能：Unit/词群下拉切换、🔍 搜索单词自动定位并高亮、点卡片朗读发音、点 ○ 折叠/展开分支、滚轮/双指缩放、拖拽平移、⬇ 导出 SVG/PNG

> 词库/导图数据更新后，在仓库根目录运行 `node tools/build-core-words.js`，再运行 `node tools/build-offline-viewer.js`，可同步词库索引并重新生成离线单文件版。
