# 英语六级词汇刷题系统

一个用于 CET-6 词汇学习的静态网站。项目把两套刘晓艳词书词库、闯关练习、间隔复习、错题回练、学习统计、词群导图和本地备份整合到一个可离线使用的应用中。

学习数据不需要账户，也不会提交到服务端。题目、词库和主要逻辑都在浏览器侧运行；学习记录只存于当前浏览器，换设备前应导出备份。

## 快速开始

### 初次打开的默认设置

新用户首次打开主站时，应用默认选择以下组合；已有学习记录时会优先恢复上次设置。

| 设置 | 默认值 |
| --- | --- |
| 词库 | 艾宾浩斯打卡 |
| 闯关 | 闯关 2：选择检测 |
| 出题方向 | 看英文选中文 |
| 题型 | 四选一 |
| 记忆模式 | 关闭（可手动开启） |
| 批次大小 | 1 页，约 20 词 |

### 开始一次练习

1. 打开 `cet6_quiz.html`。
2. 在设置区选择词库、单元、闯关、出题方向、题型和学习量；记忆模式默认关闭，需要时可手动开启。
3. 点击“开始做题”。
4. 作答后查看释义、记忆提示和可用的单词详情。
5. 到“统计”页定期导出全部数据。

可设置项及其影响如下：

| 设置项 | 可选内容 | 作用 |
| --- | --- | --- |
| 词库 | 你还在背单词吗 / 艾宾浩斯打卡 | 决定题目来源、可选 Unit、复习调度与导图能力 |
| 单元 | 全部单元或单一 Unit | 限定取题范围；单选 Unit 时会显示页进度 |
| 闯关 | 速记 / 选择检测 / Unit 综合测 | 决定答题交互与取题范围 |
| 出题方向 | 看中文选英文 / 看英文选中文 | 决定题干与答案方向 |
| 题型 | 四选一 / 默写 | 决定选择答案或输入拼写 |
| 记忆模式 | 开 / 关 | 开启后按到期状态组织学习队列 |
| 学习量 | 20 / 40 / 60 词 | 闯关 1、2 的普通学习批次；Unit 综合测覆盖完整 Unit |

## 词库与数据来源

两套词库相互独立。即使两个词库有相同拼写，错题、重点词、作答统计和复习进度也按 `core`、`full` 两个命名空间隔离，不会互相覆盖。

| 词库 | 出处 | 当前规模 | 组织方式 | 运行时来源 |
| --- | --- | ---: | --- | --- |
| 核心词库 | 刘晓艳《英语六级你还在背单词吗》 | 6,526 词 | Unit 1-14，另有补充词 | `cet6_quiz.html` 内嵌 `data-all-words` |
| 艾宾浩斯打卡词库 | 刘晓艳《六级英语核心词·艾宾浩斯抗遗忘打卡》 | **3,324 词** | Unit 1-10、每 Unit 4 个 Lesson | `data/full-words.js` 按需加载 |

### 核心词库

- Unit 1-10 为“词以群记”部分，重点词通常带词群、记忆方法、例句或派生词信息。
- Unit 11-14 为“词以序记”部分，按字母范围组织基础词汇。
- 选择“全部单元”时，未编号的补充词也会参与刷题。
- 核心词库 Unit 1-10 可使用词群导图；未覆盖词条使用兼容的回退展示。

### 艾宾浩斯打卡词库

打卡词库严格以权威 JSON 的有序数组为准。当前共 **3,324 条**，同步时保留源文件的顺序、Unit、Lesson、单词拼写和中文释义。源文件中的重复拼写仍是不同词条，不能按单词去重。

| Unit | 词条数 | Unit | 词条数 |
| ---: | ---: | ---: | ---: |
| 1 | 250 | 6 | 337 |
| 2 | 290 | 7 | 365 |
| 3 | 293 | 8 | 332 |
| 4 | 362 | 9 | 323 |
| 5 | 353 | 10 | 419 |

`data/full-words.js` 为应用补充必要的内部字段：

- `id`：从 1 开始、与源数组顺序一致的唯一编号，用于错题和复习定位。
- `unit`、`lesson`：数值型字段；页面筛选使用严格数值比较。
- `word`、`meaning`：权威词表的英文单词和中文释义。
- `seq`：同一 `Unit + Lesson` 内的顺序号，用于进度和页展示。
- `isStar`：当前权威同步词条均为 `false`。

打卡词库不显示核心词库的词群导图，因为两套书的组织方式不同；它仍完整支持选择题、默写、记忆模式、错题本、重点词、统计和词库浏览。

### 共享索引

`data/core-words.js` 是词群导图查看器使用的发音、释义和词性索引。它由核心词库与打卡词库生成，但不决定打卡练习题目。打卡练习始终以 `data/full-words.js` 的顺序和内容为准。

## 练习流程

### 闯关 1：词群速记

适合首次接触或快速复盘。

- “认识”会直接进入下一词。
- “不认识”会显示当前词可用的详情；核心词库词还会展示词群图。
- 快捷键 `1` 或空格表示认识，`2` 表示不认识。
- 建议用此模式建立初步熟悉感，再以闯关 2 验证是否能主动提取词义。

### 闯关 2：选择检测

常规学习和 Lesson 检测的主要入口。

- 四选一会从当前范围取题，并优先选择有区分度的易混词作为干扰项。
- 默写题支持键盘输入与手写输入，并进行一定程度的近似拼写判断。
- 作答后会显示正确性、释义和可用的记忆信息。
- 单选 Unit 的普通练习会按约 20 词分页，并记录位置以便下次续学。

### 闯关 3：Unit 综合测

适合完成一个 Unit 后自测。该模式覆盖选中 Unit 的完整词条，不受“每次学习量”限制。完成后可根据统计页的错误率和掌握情况决定是否重做或切入记忆模式。

### 智能练习、错题重做与重点词

- **智能练习**：优先组织重点词、薄弱词和需巩固词。
- **重做当前模式错题**：只重做当前词库、当前出题方向的错题；答对后会从相应错题集合移除。
- **重点词**：可在做题或浏览词库时标记，支持单独智能练习。
- **重做记录**：保留复练历史，用于区分偶发错误和持续薄弱点。

### 键盘操作

| 按键 | 使用场景 | 行为 |
| --- | --- | --- |
| `1` 到 `4` | 四选一 | 选择第 1 到第 4 项 |
| `1` / 空格 | 闯关 1 | 认识 |
| `2` | 闯关 1 | 不认识 |
| 空格 | 其他答题模式 | 跳过当前题，按错误处理 |
| Enter | 已完成作答 | 下一题 |
| 左方向键 | 非记忆模式 | 上一题 |
| 右方向键 | 答题中 | 下一题 |
| Escape | 输入框聚焦时 | 退出输入焦点 |

## 艾宾浩斯复习

开启记忆模式后，学习不再只是顺序做完一个批次。队列会优先包含到期复习词，然后加入当前筛选范围内未开始的新词。完成一题即从当前记忆队列移除；答错或跳过的词会按规则重新排入未来复习。

| 词库 | 复习逻辑 |
| --- | --- |
| 核心词库 | 参考书末 4 周 25 天计划，按 `+1 天 / +3 天 / +6 天 / +12 天` 组织 Unit 复习 |
| 艾宾浩斯打卡词库 | 每词 8 格：首次学习后依次为 `5 分钟 / 30 分钟 / 12 小时 / 1 天 / 2 天 / 4 天 / 7 天` |

### 到期提醒

- 有到期项目时页面会显示复习提醒。
- 点击开始复习会把到期词组为复习队列。
- 打卡词库以每词 8 格完成状态呈现进度。
- 5 分钟、30 分钟等短间隔会在当前学习会话内提醒；较长间隔会在以后打开网页时提醒。
- 调度依赖设备本地时间。大幅修改系统日期会改变到期判断。

## 词群导图和浏览器

### 词群导图

词群导图面向核心词库 Unit 1-10：中心节点是词群主题或当前词，周围节点表示同根、派生、近义、反义、形近或其他关联词。节点上的分支徽标表示还能继续展开；不同连线颜色区分关系类型，虚线用于特定关系。点击节点可逐层查看并朗读单词。

独立查看器适合不做题时集中学习词群，支持 Unit/词群筛选、搜索定位、折叠展开、缩放、拖拽、朗读和导出 SVG/PNG。`word-maps-viewer-offline.html` 已内联所需数据；普通查看器需要与 `data/` 目录一起保留。

### 单词浏览器

浏览页支持中英文搜索、分页、查看释义、标记重点词；核心词库的可用词条还可从浏览页打开词群导图。

## 错题、统计和数据备份

主要学习状态保存在浏览器 `localStorage` 的 `cet6_quiz_app_v2` 键下，包括：

- 当前设置、暂存练习进度、页位置和学习量。
- 每词作答次数、正确数、错误数和掌握状态。
- 错题记录、重做记录和重点词。
- 每日学习历史、连续学习、每日目标及统计图表数据。
- 核心库 Unit 复习状态，以及打卡库每词 8 格进度和到期时间。

### 导出、导入和恢复出厂

1. 在“统计”页点击“导出全部数据”，保存 JSON 备份。
2. 换设备时，在新设备打开同一版本或兼容版本的页面，点击“导入数据恢复”。
3. 导入会覆盖当前学习状态，确认前应先导出本机数据。
4. “恢复出厂设置”会清除本地学习数据且不可撤销，务必先备份。

备份保存的是学习状态和偏好，不包含词库文件本身。清理浏览器站点数据、使用无痕窗口或更换浏览器前，应先导出备份。

## 离线与 PWA

### 直接本地打开

下载或克隆整个仓库后，可直接双击 `cet6_quiz.html`。必须保留相对目录结构：

```text
cet6_quiz.html
data/
  full-words.js
  core-words.js
  unit-maps.js
icons/
```

只复制主 HTML 而不复制 `data/` 时，艾宾浩斯打卡词库无法加载。`file://` 方式可以练习，但浏览器通常不会在该协议下启用 Service Worker 或“安装应用”。

### 安装为 PWA

PWA 安装需要 HTTPS 或本机 `localhost`：

1. 通过 GitHub Pages、Netlify、Vercel 或任意静态服务器发布项目根目录。
2. 打开 `/cet6_quiz.html`。
3. 使用浏览器的“安装应用”或“添加到主屏幕”。
4. 首次加载后，Service Worker 会缓存主要静态资源，后续可离线使用。

安卓 Chrome/Edge 可使用“添加到主屏幕”；iPhone Safari 使用“分享 -> 添加到主屏幕”；桌面 Chrome/Edge 通常在地址栏提供安装入口。

主功能可离线运行。单词朗读优先使用系统 Web Speech API；若浏览器无可用系统语音，在线发音回退是否可用取决于网络。

## 维护词库与导图

### 更新艾宾浩斯打卡词库

`data/full-words.js` 是打卡练习的唯一运行时来源。更新时必须以权威 JSON 为准，而不能通过核心词库、导图索引或旧打卡数据反推。

推荐流程：

1. 备份权威 JSON 和当前 `data/full-words.js`。
2. 按源数组顺序生成 `window.__FULL_WORDS_DATA__`。
3. 将 `unit`、`lesson` 转为数值，原样保留源数组中的 `word` 和 `meaning`。
4. 重建连续 `id`，范围必须是 `1..总词条数`；不得按单词拼写生成 ID。
5. 在每个 `Unit + Lesson` 内从 1 重新计算 `seq`。
6. 校验数组长度、顺序、Unit、Lesson、拼写、释义和连续 ID。
7. 若导图查看器需要同步词典索引，运行 `node tools/build-core-words.js` 并检查 `data/core-words.js` 变更。
8. 若 `core-words.js` 或 `unit-maps.js` 改变，运行 `node tools/build-offline-viewer.js` 重建 `word-maps-viewer-offline.html`。

最小词条形态如下；文件可以压缩成单行，但必须是可执行的 JavaScript 赋值语句：

```js
window.__FULL_WORDS_DATA__ = [
  {
    id: 1,
    unit: 1,
    lesson: 1,
    word: 'ambition',
    meaning: 'n.野心;雄心;抱负',
    seq: 1,
    isStar: false
  }
];
```

不要用对象键或 `Set` 对权威词表去重；相同拼写可能在不同 Lesson 中作为不同学习条目出现。

### 更新核心词库和导图

核心题库在 `cet6_quiz.html` 的 `data-all-words` JSON 块内。它除基本词义外还可能包含词群、音标、记忆提示、例句和派生词。修改后应确认核心 `id` 稳定、词群字段与 `data/unit-maps.js` 匹配、JSON 未被引号或换行破坏，并重建 `core-words.js`。

词群编辑入口是 `word-map-editor.html`。Windows 可双击 `打开词群编辑器.bat`；也可手动启动本地服务：

```powershell
node dict-server.js
# 默认健康检查：http://127.0.0.1:17989/ping
```

词典服务只使用 Node.js 内置模块；它查询有道公开接口，因此编辑时的查词功能需要网络。既有刷题词库和既有导图不依赖该服务。离线查看器是生成产物，不要只手改它，否则下次构建会覆盖改动。

## 本地开发与测试

### 本地静态服务

多数功能可直接打开 HTML。调试 PWA、资源请求或本地托管行为时，可在仓库根目录启动静态服务：

```powershell
npx serve .

# 或在已安装 Python 时
python -m http.server 8080
```

在浏览器访问服务器给出的地址，再打开 `/cet6_quiz.html`。

### Playwright

仓库不提交 `package.json` 或锁文件。需要运行浏览器测试时可临时安装依赖，生成的 `node_modules` 不应提交：

```powershell
npm install --no-save @playwright/test
npx playwright install chromium

# 主应用回归测试
npx playwright test cet6_quiz.spec.js

# 打卡词库完整性与外置数据加载验证
npx playwright test cet6_quiz.spec.js --grep "external Ebbinghaus data matches|external data \(full-words.js\)"
```

测试维护原则：

- 页面地址应从仓库相对位置构造，不应依赖个人电脑的桌面绝对路径。
- 词库同步必须校验完整投影，不能只检查数量；至少应校验顺序、`unit`、`lesson`、`word`、`meaning` 和连续 ID。
- 改动外置词库后，应验证切换词库、开始四选一、Unit 筛选、错题键隔离、记忆进度和异步加载。
- 当前 UI 以 `select` 承载模式、词库、关卡和 Unit。新增测试时不要继续依赖旧的按钮或 `.freq-chip` 选择器。
- `default-config.spec.js` 目前含有机器相关的 `file://` 路径；在其他开发机运行前，应先改为该仓库的实际测试 URL。

## 部署与故障排查

### GitHub Pages 发布检查

主站完整地址为：

```text
https://adrian0314.github.io/cet6-cihui-shuati/cet6_quiz.html
```

发布前确认：

- `cet6_quiz.html`、`data/`、`icons/`、`manifest.json` 与 `sw.js` 都在发布根目录。
- 主页面动态加载 `data/full-words.js` 的相对路径未变。
- 更新离线资源时检查 `sw.js` 的缓存清单和缓存版本。
- 发布后用无痕窗口打开主站，切换到艾宾浩斯打卡并开始一题练习。

### 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打卡词库加载失败 | 缺少 `data/full-words.js`、相对路径错误或部署未更新 | 保留目录结构，检查浏览器网络请求和发布产物 |
| 本地打开没有打卡词库 | 只复制了主 HTML，未复制 `data/` | 复制整个项目目录，至少保留三个数据文件 |
| 手机不能安装 | 使用 `file://`、非 HTTPS 或浏览器不支持 | 使用 HTTPS 托管地址，再添加到主屏幕 |
| 换设备后记录消失 | 学习数据只在原浏览器本地 | 从原设备导出 JSON，再导入到新设备 |
| 导入数据异常 | 备份不是本应用导出或文件损坏 | 使用“导出全部数据”生成的 JSON，并保留原备份 |
| 查词失败 | 服务未启动、端口冲突或网络不可用 | 访问 `/ping` 检查服务，换端口启动并检查网络 |
| 发布后仍显示旧词库 | 浏览器或 Service Worker 缓存旧资源 | 强制刷新、重启已安装应用，必要时清除站点缓存 |

清除站点缓存会同时清除学习记录，应先导出备份。
