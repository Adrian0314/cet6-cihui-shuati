# 🎓 英语六级词汇刷题系统

一个**单文件、完全离线可用**的 CET-6 词汇刷题系统，词库严格来自两本纸质教辅书，支持 PWA 安装到手机/电脑，像原生 App 一样全屏使用。

> **在线体验**：https://adrian0314.github.io/cet6-cihui-shuati/cet6_quiz.html

## 📚 词库

| 词库 | 出处 | 内容 |
|---|---|---|
| 📗 核心词库 | 刘晓艳《英语六级你还在背单词吗》（东北师范大学出版社） | 6458 词。Unit 1-10「词以群记·抓核心」：核心词按词群分类，大多含记忆方法（联想/构词/对照/谐音）、经典例句，部分附扩展词；Unit 11-14「词以序记·刷基础」：大纲基础词按首字母分组——U11 A-E（1227 词）、U12 F-L（877 词）、U13 M-O（438 词）、U14 P-Z（1516 词），全部含音标与释义；另含 496 个无单元编号的补充词（选「全部」时参与刷题） |
| 📚 打卡词库 | 刘晓艳《六级英语核心词·艾宾浩斯抗遗忘打卡》（开明出版社） | 2920 词。10 个 Unit、40 个 Lesson，每词按书中 8 格打卡周期调度 |

## 📖 使用指南

### 开始做题

做题页从上到下依次设置：**词库 → 单元筛选 → 闯关模式 → 做题模式 → 题目类型 →（可选）记忆模式 → 每次学习量**，然后点「▶ 开始做题」。

- **做题模式**：看中文→选英文 / 看英文→选中文
- **题目类型**：选择题（四选一）/ 默写题（键盘输入或手写板）
- **每次学习**：1 页≈20 词，可选 1/2/3 页
- **页导航**：单选某个 Unit 做题时，顶部显示「第 X/Y 页」与本页进度；自动从上次做到的位置续刷（学完整个 Unit 最后一页后自动回到第 1 页），也可用「上一页/下一页」跳转任意页

### 🏰 闯关模式

| 关卡 | 名称 | 用法 | 适用场景 |
|---|---|---|---|
| 闯关1 | 词群速记 | 认识/不认识二选一快刷：**认识**直接进入下一词，**不认识**展示词群导图 + 单词详解。快捷键 `1`/`空格`=认识，`2`=不认识 | 首次接触新词群，快速过一遍混个脸熟 |
| 闯关2 | 选择检测 | 标准四选一 / 默写题，答完即显示详解 | 学完一个 Lesson 后的检测 |
| 闯关3 | Unit 综合测 | 一次覆盖整个选中 Unit 的全部词 | 学完一个 Unit 后的综合检测 |

**取题量**：闯关1/2 按「每次学习」页数取词；闯关3 一次性测完整个选中单元（忽略页数）。做题中切换闯关模式会先保存当前进度。

### 🧠 记忆模式

点「🧠 记忆模式」按钮开启，做题时**做完一题即从队列移除**，答错的词按当前词库的书中记忆规律自动排期回来复习：

- 每次进入记忆模式的队列 = **到期复习词** + 当前选中范围内的**未学新词**
- 做完一题即删，不回头重复；答错词进入记忆调度，到期自动回来

**记忆规律：**
- 核心词库 → 书末「4周25天打卡表」：按 **+1天/+3天/+6天/+12天** 间隔复习
- 打卡词库 → 书中每词 8 格周期：**5分/30分/12时/1天/2天/4天/7天**

**到期复习：**
- 打开网页时若有到期单词，做题页顶部显示绿色**复习横幅**，点「开始复习」四选一快刷一键清债，跳过视同答错
- 5分/30分 这类短周期在学习会话内实时提醒

注意：记忆模式是独立于闯关等级的学习方式开关，开启后按记忆调度自动排程（不按页取题）；复习只从首次作答开始计，历史数据不迁移。

### ⌨️ 快捷键

- 数字 `1-4`：选择题选答案
- `空格`：跳过（闯关1 中为「认识」）
- `回车`：下一题
- `2`：（闯关1 中为「不认识」）

## 🚀 快速开始

### 方式一：本地使用

直接双击 `cet6_quiz.html` 用浏览器打开即可。

### 方式二：安装为 App

1. 部署到任意静态托管（GitHub Pages / Netlify / Vercel）
2. 用手机浏览器打开链接：
   - **安卓**：Chrome/Edge → 菜单 →「添加到主屏幕」
   - **iPhone**：Safari → 分享 →「添加到主屏幕」
3. 安装后全屏运行、可离线使用，数据存在本地

> 注意：PWA 安装需通过 https 地址访问，本地双击打开不支持安装。
