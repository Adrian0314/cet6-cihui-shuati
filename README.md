# 六级词汇刷题网站

本目录包含离线可用的英语六级词汇刷题页 `cet6_quiz.html` 及其词库数据。

## 释义质量与选择题

- 英文选中文模式生成选项时，会比较中文核心释义并跳过完全相同或高度重叠的候选，避免同一道题出现两个无法区分的答案。
- 词库中的合法同义词不会被删除；只有在候选不足的极小自定义词池中才会使用重复释义兜底。
- `optimal` 与 `optimum` 的显示释义已区分为“最佳的/最适宜的”和“最优值/最佳状态”。`inquire` 与 `enquire` 保留原词条，但不会再作为同题的重复中文干扰项。
- 英文→中文选项会清理词库释义中混入的音标（含缺失开头斜杠的异常前缀），中文释义里的正常斜杠不会被删除；中文→英文选项仍显示独立音标辅助。
- 英文→中文选项最终仅显示中文和标点，拉丁字母、音标、词性缩写及英文括号说明会被清理；清洗后无中文的候选会被排除。
- 中文干扰项的汉字释义超过 90 字时会被过滤，优先从同词性、同前缀、易混淆或中文释义相近的候选补位，避免出现整段词典式长释义；原始词库内容不修改。

## 答题反馈与单词详解

- 答题、答错或跳过后，题目与正确答案下方紧接默认展开的“📖 单词详解”（巧记、例句、派生词）；随后显示“⚠️ 易混淆词”辨析和词群归属信息，最后显示“🗺️ 词群导图”。选择题、默写、跳过及闯关1路径保持一致；点击“单词详解”标题可收起或展开单词详解内容。

## 数据扫描

在安装 Node.js 的环境运行：

```text
node tools/scan_meaning_bugs.js
```

脚本会输出词性/音标等格式异常，以及全库标准化中文释义重复组和高重叠释义对。重复组仅用于质量审查，不代表需要删除词条。

## 本地使用

直接双击 `cet6_quiz.html` 即可离线刷题；核心词库会按需加载 `data/full-words.js`。如需运行自动化浏览器测试，请在项目目录安装 Playwright 后执行现有 `*.spec.js` 测试。
