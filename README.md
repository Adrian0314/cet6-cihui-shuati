# 🎓 英语六级词汇刷题系统

一个**单文件、完全离线可用**的 CET-6 词汇刷题网站，同时支持 PWA 安装到手机/电脑，像原生 App 一样全屏使用。

> **在线体验**：https://adrian0314.github.io/cet6-quiz/cet6_quiz.html

## ✨ 功能特色

| 功能 | 说明 |
|---|---|
| 📗 双词库 | 1500 六级核心词 + 5523 全词汇，一键切换 |
| 🔴 频率分级 | 基于 Google 20K 词频，5 级标注（必考高频 → 零频/基础），可多选筛选 |
| 🧠 间隔复习 | 艾宾浩斯自适应算法：答对间隔翻倍（1→2→4→8→16→30 天封顶），答错次日必考，到期自动横幅提醒 |
| ❌ 错题本 | 自动记录错题，支持搜索、按模式重做、答对自动移除 |
| 🎯 三种题型 | 看中文选英文 / 看英文选中文 / 默写（智能近似判定） |
| 📖 单词详解 | 答完即学：巧记（联想/构词/谐音/对照）、真题例句、派生词三板块，仿刘晓艳《你还在背单词吗》排版，1633 词全覆盖 |
| 🔇 智能混淆项 | 高频易混词优先作为干扰项，答错时展示易混淆词辨析 |
| 🔊 TTS 发音 | 一键朗读单词发音 |
| 📊 详细统计 | 正确率、连对、每日热力图、频率雷达图、覆盖率环图、趋势折线、题型柱状图 |
| ⌨️ 快捷键 | 数字 1-4 选答案、空格跳过、回车下一题 |
| 💾 数据自主 | 统计/错题/学习进度全存本地，支持导出备份、导入恢复、恢复出厂 |
| 📡 完全离线 | 图表库已内联，无网络也能用全部功能 |

## 🚀 快速开始

### 方式一：本地使用（无需网络）

直接双击 `cet6_quiz.html` 用浏览器打开即可。

### 方式二：安装为 App（PWA）

1. 部署到任意静态托管（GitHub Pages / Netlify / Vercel）
2. 用手机浏览器打开链接：
   - **安卓**：Chrome/Edge → 菜单 →「添加到主屏幕」
   - **iPhone**：Safari → 分享 →「添加到主屏幕」
3. 安装后全屏运行、可离线使用，数据存在本地

## 🗂 项目结构

```
cet6_quiz.html     主程序（单文件，含全部数据 + 图表库）
manifest.json      PWA 应用清单
sw.js              Service Worker（离线缓存）
icons/             应用图标（192 / 512 / 苹果）
```

## 🛠 技术栈

原生 HTML + CSS + JavaScript（无框架）、Chart.js（已内联）、Web Speech API、Service Worker、localStorage。
