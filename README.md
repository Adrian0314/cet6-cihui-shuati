# 🎓 英语六级词汇刷题系统

一个**单文件、完全离线可用**的 CET-6 词汇刷题系统，词库严格来自两本纸质教辅书，支持 PWA 安装到手机/电脑，像原生 App 一样全屏使用。

> **在线体验**：https://adrian0314.github.io/cet6-cihui-shuati/cet6_quiz.html

## 📚 词库

| 词库 | 出处 | 内容 |
|---|---|---|
| 📗 大纲词汇 | 刘晓艳《英语六级你还在背单词吗》（东北师范大学出版社） | 6,526 词。Unit 1-10「词以群记·抓核心」：词汇按词群分类（1,904 词），大多含记忆方法（联想/构词/对照/谐音）、经典例句，部分附扩展词；Unit 11-14「词以序记·刷基础」：大纲基础词按首字母分组——U11 A-E（1,230 词）、U12 F-L（884 词）、U13 M-S（494 词）、U14 P-Z（1,518 词），全部含音标与释义；另有 496 个无单元编号的补充词（选「全部」时参与刷题） |
| 📚 核心词汇 | 刘晓艳《六级英语核心词·艾宾浩斯抗遗忘打卡》（开明出版社） | 3,324 词。10 个 Unit、每个 Unit 4 个 Lesson，每词按书中 8 格打卡周期调度 |

**音标来源**：全部音标（含「单词详解」里的派生词音标）统一取自**有道词典**（英式优先、无英式时回退美式），不再混用 OCR 识别值与不同词典体系的窄式音标。13,220 条单词音标与 1,500 余条内联派生词音标已全部核验；个别教材自造的派生词不会凭空生成读音。

## 📖 使用指南

### 开始做题

做题页从上到下依次设置：**词库 → 单元筛选 → 闯关模式 → 做题模式 → 题目类型 →（可选）记忆模式 / 自动朗读**，然后点「▶ 开始做题」。

- **做题模式**：看中文→选英文 / 看英文→选中文
- **题目类型**：选择题（四选一，遇到已知缺失释义的词条会自动修复显示，例如 `animal` 会显示“动物”）/ 默写题（键盘输入或手写板）
- **重点词**：做题时在单词标题与音标右侧点击「☆ 标记重点」或「★ 已标记」添加/取消当前单词；切换题目后按钮会跟随当前单词并保留状态，状态也会同步到重点词列表和智能练习
- **做题进度与定位**：做题时直接显示整轮答题进度，顶部进度条中绿色表示已完成，灰色表示未完成，青绿色高亮表示当前题；切换上一题、下一题或输入题号跳转时会自动滚动跟随当前题，当前题固定显示在进度条中间（首尾题也居中）。非全屏翻题时，题卡会定位到吸顶导航栏下方，避免手机端导航遮住题面首行或全屏按钮
- **中途退出**：做题进行中会即时把当前题位、已答数量和已选答案写入本地存储；手机切到后台、刷新页面或关闭网页时，页面生命周期事件还会再次保存，重新打开后点击顶部「继续做题」即可接着完成同一队列。手机从其他应用返回后，恢复保护会忽略浏览器补发的旧「不会，跳过」事件：首次真实点击选项可正常作答，只有实际按下跳过按钮才会执行跳过；跳过点击还必须落在真实起手之后 1.5 秒内，且起手必须发生在切回前台之后，补发的旧触摸（含完整序列重放）会被整事件取消，切后台很久再回来时点击选项不会被误判为跳过，跳过按钮也不会无故闪动。4 周 25 天计划会同时保存当日进度，复习提醒也会显示实际的已完成题数和待完成题数；当天新 Unit 的全部单词学完后会记录为已完成，不会再生成同一 Unit 的整组复习；复习队列中断后重新开始时只推送当天尚未答过的词，已练过的题不会重复出现；进入新的一天后，前一天**已完成**的任务按作答记录补判并正常推进到下一天，而前一天**未完成**的任务会被清空进度并强制整份重做，当天不能改做原定当天的计划；已答完但来不及清除的旧队列也会在重进时自动丢弃。
- **朗读发音**：点击单词旁的喇叭按钮优先使用普通媒体音频，以便跟随视频/音乐的蓝牙输出；网络音频无法播放时自动回退到系统 TTS，离线时仍可使用系统 TTS
- **自动朗读**：在练习设置中切换「自动朗读：开/关」，开关会保存到本机；开启后仅在“看英文 → 选中文”时，每显示一道新题朗读一次，不会因答题反馈或局部刷新重复朗读。若浏览器限制非用户操作播放，可使用题面旁的朗读按钮
- **答题后信息顺序**：提交答案或跳过后，题目与正确答案下方紧接默认展开的“📖 单词详解”（巧记、例句、派生词）；随后显示“⚠️ 易混淆词”辨析和词群归属信息，最后显示“🗺️ 词群导图”。点击标题可收起或重新展开单词详解内容。

### 🏰 闯关模式

| 关卡 | 名称 | 用法 | 适用场景 |
|---|---|---|---|
| 闯关1 | 词群速记 | 认识/不认识二选一快刷：**认识**直接进入下一词，**不认识**先展示默认展开的单词详解，再显示词群导图。快捷键 `1`/`空格`=认识，`2`=不认识 | 首次接触新词群，快速过一遍混个脸熟 |
| 闯关2 | 选择检测 | 标准四选一 / 默写题，答完即显示详解 | 学完一个 Lesson 后的检测 |
| 闯关3 | Unit 综合测 | 一次覆盖整个选中 Unit 的全部词 | 学完一个 Unit 后的综合检测 |

**取题量**：每个闯关的做题队列都是当前筛选范围内的全部单词（闯关1/2 按书中顺序，重做模式为全部错题乱序）。做题中切换闯关模式会先保存当前进度。

### 🗺️ 词群导图

答完题自动显示当前词的词群关系图（单词浏览器点「🗺️ 导图」按钮也可查看）——中心=词群主题或当前词，四周圆圈=关联词：

- **分支徽标**：圆圈外侧的绿色数字徽标表示该词下面还有几个分支；点击带徽标的圆圈逐层展开，没有徽标的圆圈=末端词（无分支），点击朗读发音
- **连线颜色**：绿=派生（扩/合成）、蓝=同根、橙=近义、红=反义、粉=形近、灰=相关，虚线=形近/反义
- **覆盖范围**：大纲词汇 Unit 1-10（书页真实导图）；导图未覆盖的词自动回退旧版导图

### 🧠 记忆模式

点「🧠 记忆模式」按钮开启，做题时**做完一题即从队列移除**，答错的词按当前词库的书中记忆规律自动排期回来复习：

- 每次进入记忆模式的队列 = **到期复习词** + 当前选中范围内的**未学新词**
- 做完一题即删，不回头重复；答错词进入记忆调度，到期自动回来

**记忆规律：**
- 大纲词汇 → 「4周25天计划」（Unit 1-14 全部参与）：第 1-14 天每天新学一个 Unit，之后按 **+1天/+3天/+6天/+11天** 间隔复习，第 15-25 天只做复习（如第9天学 Unit 9 并复习 Unit 3、6、8；第14天学 Unit 14 并复习 Unit 3、8、11、13；第25天复习 Unit 14 收尾）。每日 Unit 顺序逐日照抄纸质打卡表，见下方「📅 4周25天计划」完整表
- 核心词汇 → 书中每词 8 格周期：**5分/30分/12时/1天/2天/4天/7天**

**到期复习：**
- 打开网页时若有到期单词，做题页顶部显示绿色**复习横幅**，点「开始复习」四选一快刷一键清债，跳过视同答错
- 5分/30分 这类短周期在学习会话内实时提醒
- 4 周 25 天计划的完成判定以**实际作答**为准：当前计划日的每个 Unit 全部单词都答过一遍（不限做题入口），计划栏即显示「当天目标已完成」
- **未完成当天计划**：不清空进度、不强制重做——计划停留在该日，已完成的 Unit 和没做完的题目（含中断的做题队列）自动延续到第二天，接着上次继续；昨天的作答记录照常有效，直到该日任务全部做完，才在下一次跨天结算时进入下一天（计划栏显示「⏳ 该日计划尚未完成，进度延续中」）

### 📅 4周25天计划（Unit 1-14）

每行第一个 Unit 是当天新学，其余是当天要复习的 Unit（严格照抄刘晓艳《你还在背单词吗》书末「艾宾浩斯抗遗忘复习打卡表」）：

|---|---|---|---|---|---|

| 第2天 | Unit 2、1 | 第11天 | Unit 11、5、8、10 | 第20天 | Unit 9、14 |
| 第3天 | Unit 3、2 | 第12天 | Unit 12、1、6、9、11 | 第21天 | Unit 10 |

### ⌨️ 快捷键

- 数字 `1-4`：选择题选答案
- `空格`：跳过（闯关1 中为「认识」）
- `回车`：下一题
- `2`：（闯关1 中为「不认识」）
- `←` / `→`：上一题 / 下一题（记忆模式除外）
- `↑` / `↓`：向上 / 向下滚动页面（电脑端；每次约 15% 视口高度，带平滑动画）。
  全屏做题、词库、错题本、统计等页面都支持。焦点在输入框里时保持浏览器原生行为，
  弹层（新手引导、复习提醒）打开时只滚弹层本身。

## 🚀 快速开始

### 方式一：本地使用

进入仓库目录，直接双击 `cet6_quiz.html` 用浏览器打开即可。

### 方式二：安装为 App

1. 部署到任意静态托管（GitHub Pages / Netlify / Vercel）
2. 用手机浏览器打开链接：
   - **安卓**：Chrome/Edge → 菜单 →「添加到主屏幕」
   - **iPhone**：Safari → 分享 →「添加到主屏幕」
3. 安装后全屏运行、可离线使用，数据存在本地

> 注意：PWA 安装需通过 https 地址访问，本地双击打开不支持安装。

### 方式三：词群编辑器（维护工具）

仓库附带词群导图编辑工具链，需本机安装 [Node.js](https://nodejs.org/)（建议 18+）：

1. 在仓库目录双击 **`打开词群编辑器.bat`**：自动检测词典服务端口（17989），未运行则拉起 `node dict-server.js`，随后在浏览器打开 `word-map-editor.html`
2. 编辑器支持：从有道词典抓取单词讲解（本地服务离线时尝试直连）、可视化编辑词群导图节点、保存回 `unit-maps.js`
3. 也可单独双击 `启动词典服务.bat` 只启动服务；改完导图重新发布即可更新网站的词群导图

> 说明：`dict-server.js` 仅用 Node 内置模块（http/https/fs），无 npm 依赖；词典数据来自有道公开接口。

### 方式四：手机快速使用

## 功能调整：2026-09-11 打卡进度跨天延续（移除每日重置）

## 修复记录：2026-09-10 电脑端 ↑/↓ 滚动页面

- **问题**：电脑端做题时按 ↑/↓ 页面不动，尤其全屏模式下完全没反应。
- **原因**：原有实现写死 `window.scrollBy`，但全屏做题时 `<body>` 是 `overflow:hidden`，
  真正滚动的是题卡内部的 `.quiz-scroll`，所以滚的容器根本不是同一个；而且这段逻辑放在
  `if (!quizActive) return;` 之后，词库、错题本等同样很长的标签页完全用不上。
- **修复**：改为**动态解析当前真正能滚动的容器**，按优先级逐层挑选——
  1. 焦点元素最近的可滚动祖先（正在某个列表里操作时优先滚它）；
  2. 全屏题卡内的 `.quiz-scroll`；
  3. 当前标签页里第一个可滚动的区块（如 `#browseList`）；
  4. 文档本身。
  每次滚动约 15% 视口高度（下限 120px），带平滑动画并遵循 `prefers-reduced-motion`；
  只有真的滚动了才 `preventDefault`，无处可滚时交回浏览器原生行为。按键处理提到
  `quizActive` 判断之外，因此各标签页都能用；输入框内、带修饰键的组合、弹层打开时
  都不接管。补发的旧按键（时间戳停留在切走之前）依旧不生效。
- **验证**：`python -X utf8 test_swipe_scroll_navigation_regression.py`（14 项，新增全屏题卡、
  词库列表、输入框豁免、补发旧按键四类覆盖）。

## 修复记录：2026-09-10 音标与切题手势

### 一、音标全面替换为有道词典读音

- **问题**：手机端多道题显示的音标"缺字符""看着不对"甚至整行没有音标。原因有两层：

### 二、重做切题手势与「不会，跳过」逻辑

- **问题**：手机把做题页切到后台、在其他 App 停留一段时间再切回后，点一次选项就会自动跳到下一题，连着四五题都这样；想点「上一题」反而被切到「下一题」。
- **原因**：切后台期间浏览器会把切走前积压的输入事件（常常是完整的 `pointerdown → pointerup → click` 序列）在回到前台时一次性补发。旧实现用 80ms / 300ms / 1.5s 多个时间窗口与"延迟一拍"互相打补丁去猜哪些事件是补发的，既漏掉一部分补发，又误伤真实操作——回上一题被冷却期吞掉、连点被当成"风暴"压制，于是"想回上一题却被切到下一题"。
- **修复**：改为**统一手势闸门**，规则收敛为四条：
  1. 起手（`pointerdown`/`touchstart`/`mousedown`）的时间戳必须晚于最近一次切到后台的时刻，切走前的补发事件在捕获阶段整批取消；
  2. 收尾事件必须落在当前手势里且时间戳不倒流——凭空出现的裸 `click` 一律不执行动作；
  3. 一个手势只属于一个起手目标：点选项的手势永远不可能触发「下一题」或「不会，跳过」；
  4. 真机触摸、回到前台后的保护窗口、以及切过后台时手机上的鼠标兼容序列，都要求"起手→收尾"有真实人手耗时（补发批次会被压成 ≈0ms）。
  闸门内不再有延迟执行和冷却期，所以真人操作一次就是一，既不吞掉也不重复。键盘激活（`detail=0` 且紧跟真实按键）单独放行。
- **验证**：`python -X utf8 test_resume_skip_ghost_regression.py`（18 项，覆盖裸 click、带切走前时间戳的重放、压缩冲刷重放、幽灵「下一题」点击，以及真人点按/长按/键盘等正向路径）与 `python -X utf8 test_swipe_scroll_navigation_regression.py`（14 项，含切后台前后的滑动与按钮切题）。
