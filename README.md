# 🎓 英语六级词汇刷题系统

一个**单文件、完全离线可用**的 CET-6 词汇刷题系统，词库严格来自两本纸质教辅书，支持 PWA 安装到手机/电脑，像原生 App 一样全屏使用。

> **在线体验**：https://adrian0314.github.io/cet6-cihui-shuati/cet6_quiz.html

## 📚 词库（严格对应纸质书）

| 词库 | 出处 | 内容 |
|---|---|---|
| 📗 核心词库 | 刘晓燕《英语六级你还在背单词吗》（东北师范大学出版社） | 4902 词。Unit 1-10「词以群记·抓核心」：核心词按词群分类，每词含记忆方法（联想/构词/对照/谐音）、经典例句、扩展词；Unit 11-14「词以序记·刷基础」：大纲基础词按字母序 |
| 📚 打卡词库 | 刘晓艳《六级英语核心词·艾宾浩斯抗遗忘打卡》（开明出版社） | 2920 词。10 个 Unit、40 个 Lesson，每词按书中 8 格打卡周期调度 |

## ✨ 功能特色

| 功能 | 说明 |
|---|---|
| 🏰 闯关模式 | 严格对应书中使用指南：闯关1「词群速记」（认识/不认识快刷）、闯关2「选择检测」（Lesson 检测，选择题/默写题）、闯关3「Unit 综合测」（覆盖整个 Unit） |
| 🧠 记忆模式 | 做完一题即从队列移除，答错的词按间隔自动排期回来复习 |
| 📅 艾宾浩斯记忆调度 | 核心词库按书末「4周25天打卡表」（+1/+2/+3/+6 天间隔）；打卡词库按书中 8 格周期（5分/30分/12时/1天/2天/4天/7天），到期自动横幅提醒一键清债 |
| 🗺️ 词群导图 | 同词群单词的放射状关系图（中心=词群主题，节点=词），点击单词朗读 |
| 🎯 三种题型 | 看中文选英文 / 看英文选中文 / 默写（智能近似判定） |
| ✍️ 手写默写 | 手写板识别单词，结合词典自动纠错 |
| ❌ 错题本 & 重做 | 自动记录错题，支持搜索、按模式重做、答对自动移除 |
| 📖 单词详解 | 答完即学：巧记（联想/构词/谐音/对照）、例句（中英对照）、派生词三板块 |
| 🔇 智能混淆项 | 高频易混词优先作干扰项，答错时展示易混淆词辨析 |
| 🔊 TTS 发音 | 一键朗读单词发音 |
| 📊 详细统计 | 正确率、连对、每日热力图、近7天趋势、题型对比、词汇掌握情况、每日目标达标庆祝 |
| 📌 单元筛选 | 手动切换 Unit（核心库 Unit 1-14 / 打卡库 Unit 1-10）与学习量（1页≈20词，可选 1/2/3 页） |
| ⌨️ 快捷键 | 数字 1-4 选答案、空格跳过、回车下一题 |
| 💾 数据自主 | 统计/错题/学习进度全存本地，支持导出备份、导入恢复、恢复出厂 |
| 📡 完全离线 | 图表库已内联，无网络也能用全部功能 |

## 🚀 快速开始

### 方式一：本地使用（无需网络）

直接双击 `cet6_quiz.html` 用浏览器打开即可。

### 方式二：安装为 App（PWA）

1. 部署到任意静态托管（GitHub Pages / Netlify / Vercel）
2. 用手机浏览器打开链接：
   - **安卓**：Chrome/Edge → 菜单 →「添加到主屏幕」
   - **iPhone**：Safari → 分享 →「添加到主屏幕」
3. 安装后全屏运行、可离线使用，数据存在本地

> 注意：PWA 安装需通过 https 地址访问，本地双击打开不支持安装。

## 🗂 项目结构

```
cet6_quiz.html      主程序（单文件，含全部数据 + 图表库）
cet6_quiz.spec.js   Playwright 自动化测试
manifest.json       PWA 应用清单
sw.js               Service Worker（离线缓存）
icons/              应用图标（192 / 512 / 苹果）
```

## 🛠 技术栈

原生 HTML + CSS + JavaScript（无框架）、Chart.js（已内联）、Web Speech API、Service Worker、localStorage、Playwright（测试）。
